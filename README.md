# Registration Page

A simple account registration form built with HTML and CSS. The page provides a clean form layout for collecting basic user details.

## Features
- Username and email input fields
- Account creation form layout
- Required-field validation using native HTML attributes
- Font Awesome icons for form elements

## Technologies
- HTML5
- CSS3
- Font Awesome

## Run Locally
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No build tools or package installation are required.

## Project Purpose
This project is a front-end practice exercise focused on HTML forms, labels, input fields, and styling.
